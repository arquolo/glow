# changelog

## 0.15.x

### Ядро и публичный API

Новые экспорты: RwLock, afma, aminmax_norm, abs2, amap_dict, astreaming, cache_status, circle, clone_exc, declutter_tb, hide_frame, imresize, imresize_categorical, imrotate, maximum_cumsum, memtrack, span_task, cumsum.
Унифицированы сообщения об ошибках и улучшена обработка исключений.

### Асинхронность и конкурентность

Полный редизайн @memoize: добавлены параметры count, nbytes, ttl, policy (LRU/MRU/none).
Улучшена потокобезопасность, поддержка асинхронных функций и батчинга.

Добавлен astreaming — асинхронный аналог streaming для коллекционирования задач по таймауту или размеру батча.
Устаревшие декораторы (call_once, shared_call, weak_memoize) заменены на обёртки над @memoize.

### Профилирование и мониторинг

Новый механизм профилирования на основе потоков (Stream): точное отслеживание concurrent calls, busy/idle time без ручного сбора.
Добавлен memtrack для фоновой записи RSS процесса в лог через интервалы.
Улучшен финальный отчёт статистики: автоматическая фильтрация функций, дающих <5% времени выполнения.
Новый модуль/скрипт memmon для мониторинга памяти процессов (RSS, USS, PSS, shared) с pretty-table выводом.

### Работа с данными и изображениями

Новые функции обработки изображений: imresize, imresize_categorical, imrotate, circle.
Улучшена работа с NumPy: afma (эффективное масштабирование/сдвиг), aminmax_norm (нормализация unsigned-массивов через LUT).

### CLI, конфигурация и типы

Полная переделка cli.py: поддержка аннотаций Meta, улучшенный парсинг типов через typing_inspection, добавлен запуск модулей по строке.
Обновлена интеграция с Pydantic v2 (__get_pydantic_json_schema__).
Улучшена поддержка генераторов/итераторов в wrap (корректная обработка StopIteration, send, throw).

### Зависимости, окружение и CI/CD

Новый экстрa-пакет memmon (prettytable, psutil).
Добавлен GitHub Actions workflow для автоматической публикации в PyPI по тегам v0.**/v1.** с использованием OIDC.

### Внутренние улучшения и кроссплатформенность

Реализация потоков метрик для профилирования.
Исправления Windows-специфичных проблем: очереди, futures, thread_quota, таймауты.
Улучшена работа с shared memory.

Патч значительно модернизирует библиотеку под актуальные стандарты Python, улучшает типобезопасность, расширяет возможности асинхронного батчинга и кэширования, а также добавляет новые инструменты для профилирования и CLI.

## 0.14.x

Расширено тестирование генераторов

Добавлены проверки корректной работы методов .throw(), .close() и обработки исключений внутри генераторов.
Уточнена работа с контекстом исключений (__context__), соблюдение PEP 479 (автоматическое преобразование StopIteration в RuntimeError) и освобождение локалей фрейма после закрытия генератора.
Усиление безопасности при работе с общей памятью (test/test_shm.py)

Перед записью данных в буфер self.shm.buf добавлена явная проверка assert buf is not None, что предотвращает потенциальные AttributeError при неинициализированном ресурсе.
Введены тесты для утилиты расчёта памяти (test/test_sizeof.py)

Создан новый модуль с исчерпывающим покрытием функции sizeof: примитивы, вложенные коллекции, циклические ссылки, numpy/torch массивы, кэшированные функции и проверка производительности на больших объектах.
Исправлены предупреждения статического анализатора (test/test_thread_pool.py)

### Итог

Патч фокусируется на повышении качества тестового покрытия (особенно для генераторов и утилиты sizeof), добавлении защитных проверок в тестах и настройке линтинга. Изменений в основной бизнес-логике проекта в данном фрагменте нет.

## 0.13.x

### Архитектурный сдвиг

Библиотека полностью отделилась от PyTorch и задач глубокого обучения. Удалены nn, metrics, transforms, distributed и каталог примеров (examples/).
Все утилиты перенесены из glow.core.* в корневой пакет glow.*. Теперь это чистый набор функциональных инструментов для Python.

### Новые возможности

- Встроенный отладчик IceCream (ic, ic_repr) с продвинутым выводом: поддержка format_spec, автоматическое форматирование NumPy-массивов (статистика, градиенты, битовые пакеты).
- Новые функции для работы с массивами: aceil, afloor, apack, around, pascal (оптимизированные аналоги np.ceil/floor/round).
- Функция groupby(iterable, key) для группировки элементов итерируемых объектов.
- Публичный доступ к get_executor() в модуле параллельных вычислений.
- Добавлен параметр disable: bool = False в timer() и time_this() для условного отключения профилирования без удаления контекстных менеджеров.
- Встроенный патчер len(): теперь корректно работает с zip, map, deque, OrderedDict и другими итераторами через length_hint.

### Улучшения API и утилит

- Улучшено форматирование SI-префиксов (si, si_bin) с автоподбором точности и поддержкой спецификаторов формата.
- Добавлена полная поддержка Pydantic 2.x для класса Uid (новые методы валидации/сериализации).
- Исправлена работа map_n_dict: добавлен strict=True в zip() для строгой проверки длин.
- Убраны устаревшие обёртки совместимости (from __future__ import annotations, условная инициализация asyncio.Lock), код приведён к единому стилю Python 3.10+.

### Требования и зависимости

Переработаны опциональные зависимости: добавлен пакет ic для отладки, в io заменён opencv-python на opencv-python-headless.
Патч представляет собой масштабную чистку и фокусировку библиотеки на универсальных функциональных утилитах Python, при этом сохраняя параллельные вычисления, профилирование, кэширование и отладочные инструменты.

## 0.12.x

### Структура и сборка

- Переход на pyproject.toml (Hatchling), удаление setup.py/setup.cfg.
- Изменение структуры проекта: исходники перенесены в src/glow/, примеры и тесты вынесены в корень.

### core

- Итераторы: Значительно улучшена поддержка len() для встроенных итераторов (zip, map, islice). Переписаны windowed, chunked, ichunked с поддержкой срезов, добавлена функция ilen(). Удалены as_sized и partial_iter.
- Параллелизм: Полностью переписан _parallel.py. Добавлен max_cpu_count() с защитой от утечек VMS на Windows. Улучшен buffered, внедрён динамический размер чанков (_AutoSize) и новая функция map_n_dict. Добавлен ThreadQuota для управления пулом потоков.
- Профилирование: timer теперь использует наносекунды, time_this собирает детальную статистику (CPU/IDLE время, кол-во активных потоков) и выводит её при завершении программы.
- Кэширование и конкурентность: memoize поддерживает неограниченный кэш (capacity=None) и учёт размера в байтах (bytesize). Добавлен weak_memoize, переписан streaming с улучшенной логикой батчинга.

### Neural Networks (nn)

- Загрузчики данных: make_loader заменён на новый API get_loader() с цепочечными методами (.batch(), .shuffle(), .pin_memory()). Явная настройка процессов/потоков убрана.
- Тренировка: Внедрён класс Trainer вместо Stepper. Поддерживает стадии train/eval, автокеастинг (FP16/BF16), накопление градиентов (grad_steps).
- AMP: Заменён на get_grads() с поддержкой кастомных скалеров, механизмом повторных попыток при переполнении и интеграцией планировщиков LR.
- Модули сети: Добавлен ConvCtx для унифицированной настройки свёрток/нормализаций/активаций. Внедрены современные блоки: DenseBlock, SqueezeExcitation, ResidualBlock, MaxVitBlock, VitBlock, Attention, FeedForward. Добавлены ленивые нормализации (LazyLayerNorm, LazyGroupNorm) и стандартизация весов (Conv2dWs).
- Прототипы: Новые фабрики моделей: fc_densenet, vit, max_vit.

### Метрики, IO, CLI и Утилиты

- Метрики: Добавлены разреженные версии преобразований (to_index_sparse, to_prob_sparse), улучшена поддержка DDP, добавлена метрика dice.
- IO: Полностью удалён Slide (работу с мультимасштабными изображениями). Улучшен Sound: добавлен метод save(), строгая типизация.
- CLI: Значительное улучшение парсинга аргументов из dataclasses: поддержка вложенных структур, исправлена обработка Optional/Literal, добавлена fallback-логика для разрешения типовых аннотаций.
- Утилиты: Добавлены контекстные менеджеры detach_(), eval_() и функция materialize() для принудительной инициализации ленивых модулей.

### Breaking Changes
- Удалён io.Slide, изменены сигнатуры make_loader → get_loader, Stepper → Trainer, get_amp_context → get_grads

## 0.11.x

### Параллельные вычисления (glow.core._parallel)

mapped() заменён на map_n() и starmap_n(). Добавлен точный контроль над воркерами (max_workers), порядком результатов (order), префаetch-ом и размером чанков.
buffered переделан из функции-обёртки в dataclass с улучшенной обработкой очередей и безопасным завершением потоков.

### CLI-парсер (glow.cli)

arg() теперь автоматически распознаёт типы Literal, list[...], Optional[...] и поддерживает пользовательские флаги через параметр flag.
Добавлен параметр prog в parse_args(). Улучшена валидация позиционных и опциональных аргументов.

### Работа с изображениями (glow.io)

Класс TiledImage и функция read_tiled() переименованы в Slide и Slide.open().
Унифицирован интерфейс мультимасштабных изображений (SVS, TIFF): поддержка ndarray-слайсинга, кэширование через _from_path, улучшена обработка corrupted tiles.

### Трансформации (glow.transforms)

Compose переименован в Chain.
Добавлена вероятностная композиция: операторы *prob / __rmul__, класс _Maybe (условное применение) и _OneOf (случайный выбор одной трансформации).
Функция dither вынесена в отдельный модуль с JIT-оптимизацией через numba. Улучшена типизация (NumpyLike protocol) и репрезентация.

### Профилирование (glow.core._profile)

Декоратор time_this() теперь отслеживает не только вызовы функций, но и итерации генераторов (Iterator). Выводит детальную статистику: общее время, время на вызов/итерацию, процент от общего времени и кол-во потоков.

### PyTorch / Neural Network

- AMP переключён на современный torch.autocast(device.type, fp16) вместо устаревшего torch.cuda.amp.
- Контекст инференса использует torch.inference_mode() вместо torch.no_grad().
- Во всех DataLoader и параллельных загрузчиках параметр num_workers заменён на max_workers.
- Исправлена логика инициализации состояния в оптимизаторе SGDW.

### Общее / Зависимости

Переструктурированы extras (cv-dither, memprof), обновлены конфиги линтеров (flake8/mypy).
Упрощён интерфейс shared-memory для мультипроцессинга через move_to_shmem(). Оптимизирована генерация ключей в memoize.
Все изменения направлены на повышение производительности, улучшение типизации, унификацию API и переход на современные аналоги PyTorch.

## 0.10.x

### Новый функционал

cli: добавлен модуль для автоматической генерации CLI-парсеров из сигнатур функций или dataclass. Поддерживает позиционные/именованные аргументы, вложенные структуры и типы Optional/list.
api.env: новая система управления окружением на базе ChainMap. Работает как контекстный менеджер и декоратор. Заменяет устаревшие patch/Default.
cv.Mosaic: класс для работы с тайлами изображений: разбиение, обработка с перекрытием (overlap), параллельное применение функций и взвешенное слияние без артефактов на границах.
core.Uid: компактное представление UUID (22 символа, base57) вместо стандартных 32-символьных hex-строк. Быстрая сериализация/десериализация.
nn.util.LazilyTraced: обёртка для ленивого JIT-трейсинга моделей PyTorch с поддержкой сохранения в pickle.

### Изменения API и интерфейсов

io.Sound: полностью переписан. Убран ObjectProxy, добавлены свойства duration, channels. Бэкенд воспроизведения заменён на sounddevice (добавлена поддержка прерывания через Ctrl+C).
io.TiledImage: метод срезов __getitem__ теперь сразу возвращает np.ndarray. Убран вызов .view(), добавлена строгая валидация шагов и корректная обработка границ/фона.

Форматирование чисел: класс Si заменён на функциональные интерфейсы glow.si() и glow.si_bin(). Они возвращают исходный тип числа (int/float) с поддержкой __format__, не ломая арифметику.
Профилировщики memprof и timer: теперь принимают коллбек или имя, автоматически определяя место вызова через новую функцию whereami.

### Архитектурные изменения

transforms: модуль полностью переработан в пакет (core, classes, functional). Внедрены протоколы (ImageTransform, MaskTransform, DualStageTransform) и dataclass-декораторы для трансформаций. Старый плоский API удалён.
nn.modules: устаревшие фабрики перенесены/удалены. Основные строительные блоки (resblock, Cat, Sum, SEBlock, SplitAttention, conv, upconv) реализованы как готовые классы/функции с поддержкой ResNet/ResNeSt/WideResNet паттернов.
Удалён interpreter_lock и связанные механизмы принудительной блокировки переключения потоков.

### Производительность и стабильность

core.sizeof: переписан с использованием CPython-интроспекции (_PyObject_GetDictPtr). Теперь возвращает точный размер в байтах (int) без рекурсивных обёрток, работает быстрее и надёжнее.
Параллельные пулы (glow.core._parallel): улучшена обработка ошибок при завершении воркеров, оптимизирована очередь submit, убрана зависимость от interpreter_lock.
Улучшена работа с альфа-каналом и фоновыми цветами в _tiled.py (Openslide/Tiff).

### Зависимости и конфигурация

Конфигурация разработки: настройки линтеров (flake8, mypy, yapf) перенесены из отдельных файлов в setup.cfg для единого центра управления.
Экстры установки переименованы/перегруппированы: glow[nn], glow[io], glow[cv], glow[all].

### Примечание

Патч содержит несколько breaking changes (удаление .view() у TiledImage, замена Si на функции, перенос трансформаций в пакет, удаление interpreter_lock). При обновлении потребуется минимальная адаптация существующего кода.
